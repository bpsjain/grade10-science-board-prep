# ScienceEval AI

An AI-powered tool to evaluate student answers for CBSE Science, 
aligned with Bloom's Taxonomy.

Live App: [Click here to try it](https://cbse-competency-evaluator.streamlit.app/)

---

## What it does

- Takes a science question and student answer as input
- Evaluates the depth of understanding using Bloom's Taxonomy
- Identifies expected vs achieved understanding level
- Extracts evidence from the student's answer
- Highlights learning gaps
- Suggests next steps for improvement

---

## Who is it for

- Teachers who want quick, structured feedback on student answers
- Students who want to self-evaluate their answers
- Anyone exploring AI in education

---

## Built With

- Python
- Streamlit
- OpenAI API (gpt-4o-mini)

---

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run ScienceEval.py
```
